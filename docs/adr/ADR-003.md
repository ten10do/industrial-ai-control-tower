# ADR-003: React + TypeScript Frontend

## Status

Accepted

## Context

The frontend must render real-time industrial dashboards, forms for human approval, and diagnostic visualizations. It must be maintainable as the application grows.

## Decision

Use React with TypeScript, bundled by Vite.

## Alternatives

- **Vue**: Excellent ergonomics, but the team ecosystem leans toward React.
- **Angular**: Full-featured, but heavier and more opinionated than needed.
- **Next.js**: Good for SSR/SSG, but adds server-side complexity that is unnecessary for a dashboard that will primarily consume an API.

## Consequences

- Strong component model with a large ecosystem.
- TypeScript catches contract mismatches with the backend early.
- Vite provides fast dev builds and a modern plugin system.
- State management, routing, and UI component libraries will be added in later phases as requirements solidify.
