# ADR-010: Observability Strategy

## Status

Provisional — to be confirmed in Phase 7

## Context

A multi-agent industrial system must be debuggable, auditable, and performant. Observability needs to cover logs, metrics, traces, and agent evaluation.

## Decision

Adopt structured logging immediately, and add Prometheus metrics, OpenTelemetry traces, and Grafana dashboards as the system matures.

## Alternatives

- **Plain text logs only**: Insufficient for distributed debugging.
- **Vendor-specific APM**: Lock-in and potential data sovereignty concerns.

## Consequences

- Structured logs from day one simplify future parsing and alerting.
- Metrics will track API latency, agent run duration, and queue depths.
- Traces will follow requests across backend, agents, and external calls.
- Agent evaluation metrics will be added once agents are implemented.
- Secrets and sensitive prompts must never be logged.
