# ADR-004: PostgreSQL Primary Persistence

## Status

Accepted

## Context

The platform must persist structured domain entities (devices, alarms, incidents, diagnoses, approvals, work orders) with strong consistency, relational integrity, and auditability.

## Decision

Use PostgreSQL as the primary relational database.

## Alternatives

- **MySQL**: Capable, but PostgreSQL has stronger support for JSON, full-text search, and complex constraints.
- **SQLite**: Simpler for local development, but not suitable for concurrent production workloads.
- **MongoDB**: Flexible schema, but relational integrity and transactional guarantees are weaker.

## Consequences

- ACID transactions for critical business operations.
- Rich indexing and query capabilities.
- Migrations managed by Alembic.
- Future vector search will be handled by a dedicated vector store, not PostgreSQL JSONB, to avoid impedance mismatch.
