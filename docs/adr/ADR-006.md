# ADR-006: LangGraph Orchestration Strategy

## Status

Provisional — to be confirmed in Phase 5

## Context

The platform will coordinate multiple AI agents (Diagnosis, Knowledge, Planning, Safety, WorkOrder). We need a workflow engine that supports branching, loops, human-in-the-loop interrupts, and state persistence.

## Decision

Plan to use LangGraph as the orchestration framework.

## Alternatives

- **Custom state machine**: Maximum control, but requires building interrupts, persistence, and retries from scratch.
- **Temporal / Cadence**: Industrial-strength workflow engines, but add operational complexity and are not purpose-built for LLM agent cycles.
- **LangChain Expression Language (LCEL)**: Good for linear chains, but less explicit support for cyclic, stateful agent workflows.

## Consequences

- LangGraph provides explicit graph structure for agent workflows.
- Built-in support for interrupts enables human approval checkpoints.
- Persistence supports long-running diagnosis sessions and crash recovery.
- LangGraph is still evolving; we will re-evaluate before committing production workloads.
